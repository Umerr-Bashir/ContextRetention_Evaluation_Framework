# StudentHub Readme 

## **1. Introduction** 

StudentHub is a campus society management Android application designed as a Final Year Project (FYP). It helps students connect with university societies, explore campus events, join communities, and create their own societies. The main goal is to improve student engagement, communication, and participation in university activities through a centralized platform. 

## **2. System Requirements** 

Android version 8.0 (Oreo) or above 

Minimum 2 GB RAM 

Stable internet connection 

Google Play Services required for login 

Sufficient storage space for installation 

## **3. Installation & Launch** 

Installation Steps: 

- Download APK 

- Install on Android device 

- Allow permissions 

Launch Steps: 

- Open StudentHub app 

- Wait for splash screen 

- Proceed to onboarding 

## **4. Onboarding & User Setup** 

University Selection: Search and select university 

Department Selection: Choose academic department 

Semester Selection: Select current semester 

Interest Selection: Choose interests like Tech, Sports, Arts, Business 

These preferences personalize recommendations. 

## **5. Authentication (Login System)** 

Users can sign in using Google account or skip login. Login enables saving data, syncing societies, and full access to features. 

## **6. Home Screen (Dashboard)** 

Displays personalized recommendations, trending societies, and campus highlights. If no societies are joined, an empty state is shown. 

## **7. Explore Societies** 

Users can search, browse featured societies, and view trending communities. Each society shows name, logo, description, followers, and join option. 

## **8. Society Details Page** 

Contains full description, events, updates, followers, and university information. Users can join societies and view activities. 

## **9. Joining a Society** 

Tap 'Join Society' to become a member. Joined societies appear in profile and provide access to updates and events. 

## **10. Creating a Society** 

Tap '+' button and fill required fields: name, category, university, description, cover image, logo. Submit using Create Society button. 

## **11. Profile Section** 

Shows academic information, joined societies, and activity statistics. Helps users track participation and memberships. 

## **12. Navigation System** 

Home: Dashboard 

Explore: Discover societies Communities: Updates & events 

Profile: User information 

## **13. Application Workflow** 

Install app **→** Launch **→** Onboarding **→** Select info **→** Choose interests **→** Login **→** Feed loads **→** Explore **→** Join/Create society **→** Manage profile 

## **14. Troubleshooting** 

App not loading: Check internet 

Login issues: Enable Google Play Services 

Cannot create society: Fill all fields 

Search issues: Check spelling 

## **15. Future Enhancements** 

Chat system, Notifications, QR attendance, AI recommendations, Event reminders
